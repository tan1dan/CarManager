## Vehicle brand and model catalog

`CarManager/CarManager/Resources/VehicleCatalog.json` is an adapted version of the
**vehicle-makes-models** dataset (https://github.com/gor3a/vehicle-makes-models),
whose data was compiled from publicly available information on autoevolution.com.

- Source data licence: Open Database License (ODbL) v1.0 —
  https://opendatacommons.org/licenses/odbl/1-0/
- Source revision: `b4965631140fa82404359167621274601da69a5b`
- Changes made: only the make/model/year columns are kept; model names are cleaned
  (a repeated brand prefix is removed, German/English class names are unified, spacing and
  capitalisation are normalised) and duplicates are merged. Popular-brand flags and search
  aliases are added by this project.

The adapted database (`VehicleCatalog.json`) is made available under the **ODbL v1.0**, as
the share-alike term requires. It is regenerated by
`CarManager/tools/vehicle-catalog/build_catalog.py`.

The app shows this attribution in the brand picker.
